# MarkICP User

Веб-застосунок Marki для покупців: каталог, NFT-паспорти товарів, покупки й доставки.

Створено з бізнес-кабінету [MarkICP](https://github.com/AlanKharisov/MarkICP) і адаптовано під покупців:

- вхід і реєстрація (email або Google) без перевірки компанії, другий крок — профіль Marki;
- **Головна**: що потребує уваги (посилки поруч, замовлення в дорозі), швидкі дії, нове в каталозі;
- **Каталог**: товари брендів, пошук, картка товару, замовлення з оплатою при отриманні;
- **Мої замовлення**: статуси доставок, історія, «Я отримав(ла) товар»;
- **Перевірити товар**: NFC-сканування (Chrome на Android) або код мітки вручну;
- **Мої NFT**: цифрові паспорти з QR і посиланням;
- гаманець, стрічка, сповіщення, профіль користувача.

Бекенд спільний з кабінетом компаній (`idenity/api`).

Стек: **Vite + React + TypeScript + Internet Computer (ICP / Plug Wallet) + Firebase Auth**.

## Запуск

```bash
npm install
cp .env.example .env.local   # Firebase і адреса API
npm run dev                  # http://localhost:3002
```

## Змінні оточення

| Змінна | Призначення |
|---|---|
| `VITE_API_BASE_URL` | Rust API (`idenity/api`), напр. `https://idenity.onrender.com` |
| `VITE_FIREBASE_*` | Firebase Auth (той самий проєкт, що й у кабінету компаній) |

## Скрипти

| Скрипт | Що робить |
|---|---|
| `npm run dev` | Dev-сервер на :3002 |
| `npm run build` | Збірка в `dist/` |
| `npm run preview` | Перегляд збірки |

## Структура

- `src/pages/` — Головна, Каталог, Замовлення, Перевірка, Мої паспорти, публічний паспорт, Стрічка, Гаманець, Сповіщення, Профіль.
- `src/Shell.tsx` — меню (на телефоні — нижня панель з кнопкою сканування по центру).
- `src/api.ts` — клієнт API з читабельними помилками.

## Посилання на паспорт

`/?nft=<id>&owner=<uid>` — публічна сторінка паспорта; власник перевіряється через `POST /api/nfts/verify`.
`/?nfc=<uid>` — сторінка за NFC-міткою.
